This repository hosts the **built, static output** of the IbiScript reference manual, served via GitHub Pages at:

**→ https://ibiscript.ozzurram.com**

IbiScript is a Leiden-convention epigraphic transcription DSL developed as part of the
Paikuli Digital Epigraphy (PDE) project, Sapienza Università di Roma — "Persistenza
dell'Antico" Project of Excellence.

This repo contains generated HTML/CSS/JS only (produced by an internal `typst2mdbook`
pipeline) — not the manual's source content or the IbiScript/PDE application source.
